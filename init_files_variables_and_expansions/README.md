# Shell, init files, variables and expansions

- 0-alias: Creates an alias named ls with the value rm -f *.
- 1-hello_you: Prints hello followed by the current user's name.
- 2-path: Appends /action to PATH.
- 3-paths: Counts the entries in PATH.
- 4-global_variables: Lists environment variables.
- 5-local_variables: Lists shell variables and functions.
- 6-create_local_variable: Creates the shell variable BEST.
- 7-create_global_variable: Exports the environment variable BEST.
